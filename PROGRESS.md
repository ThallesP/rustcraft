## Needs Thalles

- **A Microsoft account for online mode.** A vanilla server only encrypts in online mode, where it checks the player with Mojang's session server, so checking `Connection`'s encryption (`Crypt`, `CipherDecoder`, `CipherEncoder`) and the online-mode login (`ClientHandshakePacketListenerImpl.handleHello`, `authenticateServer`) against vanilla needs a Minecraft Java account that both the oracle client and the port log in with (Microsoft's OAuth, then a Minecraft access token), and a local server with `online-mode=true`. Needed: an account to test with, and where its credentials may live on this machine (outside git). Until then the port joins offline-mode servers only, and the encryption's byte-level parts can still get goldens (AES/CFB8 and the RSA key exchange on fixed keys). Not blocking: the rest of the net track goes on.
- **Licence of the code translated from OpenJDK, JOML, Netty and Guava.** `src/java/lang/math/hotspot_x86/` is translated from OpenJDK's HotSpot, which is GPLv2 only (no Classpath Exception), and keeps its notices. `src/java/lang/fd_libm.rs` comes from the JDK's `FdLibm.java`, GPLv2 with the Classpath Exception, `string::from_bytes_utf8` from the JDK's `String.java`, and `src/jdk/internal/math/` from `DoubleToDecimal.java`, `FloatToDecimal.java`, `ToDecimal.java` and `MathUtils.java`, `src/java/util/hash_map.rs`, `src/java/util/hash_set.rs` and `src/java/io/` from `HashMap.java`, `HashSet.java`, `DataInput.java`, `DataOutput.java`, `DataInputStream.java`, `DataOutputStream.java` and `ModifiedUtf.java`, the same, which keep their notices. `src/org/joml/` comes from JOML, MIT, whose notice a distribution has to carry. `src/io/netty/` comes from Netty, Apache 2.0, and keeps its notice, saying the files were translated and changed; a distribution has to carry the licence too. So does `src/com/google/`, from Guava, also Apache 2.0. That's fine while the repo stays private. Shipping a build of rustcraft would put it under GPLv2 too, and Apache 2.0 code isn't compatible with GPLv2 only. Not blocking. Decide before the repo or any build goes public.
